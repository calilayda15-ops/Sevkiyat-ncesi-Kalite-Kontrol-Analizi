This project is about a quality control test for a 1,000-box fruit export. I used a data set of 18 boxes and selected 4 random samples for analysis.
The Analysis:
I used Excel and Python to check the moisture levels and labels. I found that box K-003 has a high moisture level (14.7%), which is above the 12.9% limit.
The Results:
The quality score of the shipment is 72%. This is lower than the international standard (95%). Because of this 25% error rate, we stopped the shipment to prevent extra costs.
Technical Steps:
I cleaned the data with the TRIM function and converted labels to numbers (1 for OK, 0 for Error). This helped me calculate the final success score easily.
